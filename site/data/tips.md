## v2.4 リリース
### 新機能
- お気に入りリストの素材リストに、**個数指定**を追加しました。
  アイテムごとに作りたい数を指定し、合計に必要な素材を確認できます。
- お気に入りリストの素材リストに、**どれでも1つ**を追加しました。
  チェックしたアイテムのうち、どれか1つを作れる最低限の素材リストを表示できます。
- お気に入りリストの素材リストで、対象アイテムを画像付きで表示するようにしました。
- 採集時間が決まっている素材に、**⏰ 採集情報**ボタンを追加しました。
  エリア、マップ、ET時間、採集方法、伝承録、必要技術力を確認できます。
- 交換貨幣に **同盟記章** を追加しました。

### 仕様変更
- 素材リストやレシピツリーの展開/折り畳みに、伸び縮みアニメーションを追加しました。
- 素材リストの展開/折り畳み状態を、再読み込み後もできる限り復元するようにしました。
- お気に入りリストのシェア対象から、検索履歴を外しました。
- 起動時の「データ読み込み中」を中央表示にし、読み込み状態が分かりやすくなるよう調整しました。
- 素材リストとレシピツリーの補助ボタン配置を調整し、601px以上ではアイテム名の近くに表示するようにしました。
- 採集情報ウィンドウの横幅、時間帯表示、閉じるボタン位置を調整しました。

### 使い方
| 操作 | 内容 |
|---|---|
| **個数指定** | お気に入り内のアイテムごとに、作りたい個数を指定します。 |
| **どれでも1つ** | チェックしたアイテムのうち、どれか1つを作れる素材リストを表示します。 |
| **全て1個 / 全て0個** | 個数指定中に、お気に入りリスト内全アイテムの個数をまとめて変更します。 |
| **全てOn / 全てOff** | どれでも1つ中に、お気に入りリスト内全アイテムのチェック状態をまとめて変更します。 |
| **⏰** | 採集情報がある素材の場所とET時間を表示します。 |
| **🌲** | 中間素材のミニレシピツリーを表示します。 |

### バグ修正
- スマホ表示で、縦スクロールバーの出入りにより表示幅が揺れる場合がある問題を軽減しました。
- ミニレシピツリーの折り畳み時に、ウィンドウの縦幅や下部余白が不自然に変わる場合がある問題を修正しました。
- 素材リストの一部セクションで、折り畳み/展開が効かない場合がある問題を修正しました。
- 無属性クリスタルが、必要なシャード/クリスタル/クラスター欄に分類される問題を修正しました。
