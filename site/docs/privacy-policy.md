# プライバシー・ポリシー

本ポリシーは、XIVca運営者が本アプリの提供、不具合報告およびお問い合わせの受付に伴って取り扱う情報、その利用目的、送信先、保存と問い合わせについて説明するものです。

## 利用目的

取得した情報は、不具合の再現・原因調査・修復、性能と使いやすさの改善、およびお問い合わせへの返信に使用します。お問い合わせへの返信には、利用者が記入した連絡先を使用します。

また、下記「誹謗中傷・迷惑行為への対応」に定める行為について、被害の防止、事実確認および紛争への対応のため、関連する情報を必要な範囲で使用することがあります。

## ブラウザー内に保存する情報

表示設定、お気に入り、製作ステータス、生成したマクロ、生成条件、動作記録およびアプリのキャッシュを、利用者のブラウザー内に保存します。これらは設定の維持やアプリの動作に使用します。不具合報告として送信する情報は、利用者が送信を確定した報告に添付する範囲に限られます。

## 不具合・その他お問い合わせで取得する情報

入力された本文に加え、問い合わせ時の利用環境、データの版、関連する日時、および使用中の各パネルの情報を、利用者による送信の確定後に送信します。左・中央・右パネルの情報には、検索条件、表示内容、選択中のアイテム、製作数、素材のチェック状態などが含まれます。未使用のパネルの情報は添付しません。

マクロパネルを使用している場合は、製作アイテム、レシピ、クラフターステータス、中間素材のHQ・NQ、選択した食事と薬品、生成結果、通知・エラー、処理時間やメモリー使用量などの動作記録、生成エンジンの版も添付します。対象のレシピに対応する保存済みの生成記録を含む場合があります。マクロパネルを閉じている場合は、保存済みのものを含め、マクロ関連情報を添付しません。

## 任意のスクリーンショット

利用者が選択または貼り付けた画像だけを添付します。画面の自動撮影は行いません。画像はブラウザー内で送信用に圧縮・縮小し、形式を変換する場合があります。送信する画像は、送信前の画面で確認・削除できます。

画像に氏名、連絡先、お気に入りリスト名などが写っている場合、その内容も送信・保存の対象となります。画像は本文や診断情報と同じ利用目的・送信先・保存方針で取り扱います。

## 個人を識別する情報の取り扱い

不具合報告の診断情報として、氏名、メールアドレス、電話番号、住所、端末の製造番号、IMEI、MACアドレス、広告識別子、位置情報を自動取得しません。Cookie、他サイトの閲覧履歴、ブラウザーの保存領域全体も報告に添付しません。

利用者が報告本文に氏名や連絡先などを記入した場合は、その内容も取得・保存の対象となります。

デバイス情報は機種や利用環境を示すものであり、個人の追跡や端末固有の識別子の生成を目的として利用しません。ただし、入力された個人情報などと組み合わさることで、個人を識別できる場合があります。

## 取得するデバイス・ブラウザー情報

不具合の再現と利用環境による動作差の調査のため、次の情報を取得し、不具合報告に添付します。取得範囲はブラウザーが公開する情報に限られます。

- **言語**：ブラウザーに設定されている言語です。
- **画面全体の幅**：端末の画面の横幅です。
- **画面全体の高さ**：端末の画面の縦幅です。
- **ページ表示領域の幅**：アプリ全体が表示されている領域の横幅です。
- **ページ表示領域の高さ**：アプリ全体が表示されている領域の縦幅です。
- **パネル表示領域の幅**：使用中のパネルの表示領域の横幅です。
- **パネル表示領域の高さ**：使用中のパネルの表示領域の縦幅です。
- **ピクセル比**：画面上の表示サイズと端末の画素数の比率です。
- **表示倍率**：ページの可視領域の拡大率です。
- **セキュアコンテキスト**：ブラウザーがページを安全な実行環境と判定しているかどうかです。
- **分離コンテキスト**：ページが他の配信元から分離された実行環境にあるかどうかです。
- **ページ表示状態**：ページが表示中か、背面などで非表示になっているかという状態です。
- **ブラウザー名**：使用しているブラウザーの製品名です。
- **ブラウザーバージョン**：ブラウザーの版番号です。内部で使用するChromiumの版番号を含む場合があります。
- **ブラウザー判別方法**：ブラウザー名と版番号の情報源です。
- **UserAgent**：ブラウザーが公開する、ブラウザーやOSなどの環境を示す文字列です。
- **端末型番**：端末の機種名です。端末一台ごとの製造番号ではありません。
- **OS**：使用しているOSの名称です。
- **OSバージョン**：ブラウザーが公開するOSの版番号です。
- **論理プロセッサ数**：ブラウザーが公開する、並列処理能力の目安となる数値です。
- **搭載RAM概算**：ブラウザーが公開する搭載メモリーの概算量です。現在の空き容量ではありません。

## 送信先と情報の保護

不具合報告はXIVca運営者が受信・保存し、報告内容の閲覧は原則としてXIVca運営者に限定します。ただし、下記「誹謗中傷・迷惑行為への対応」に定める根拠に基づき、対応に必要な範囲で情報を提供する場合を除きます。

報告内容はHTTPSにより暗号化して送信します。

接続元IPアドレスは、過剰な送信を防止するための自動処理にのみ使用し、XIVca運営者は閲覧・保存しません。報告本文にも含めません。通信サービスによる通信の提供・保護に必要な情報の取り扱いは、各サービスの方針に従います。

## 保存と削除

報告本文、添付された診断情報・画像、本文に記入された連絡先は、報告の受信先に保存されます。ブラウザー内の保存データは利用者がサイトデータを削除することで削除できますが、送信済みの報告は別に保存されています。

送信済み報告の確認や削除については、下記の窓口へご連絡ください。該当する報告を確認するため、送信日時や報告内容をお尋ねする場合があります。

## 誹謗中傷・迷惑行為への対応

不具合報告やお問い合わせにおいて、運営者や第三者に対する人格を否定する侮辱、脅迫、差別的な言動、執拗な嫌がらせ、対応を妨げる大量・反復送信などが確認された場合は、内容や状況に応じて、回答の中止やお問い合わせへの対応の制限を行うことがあります。通常のご意見、ご批判、不具合のご指摘を理由に、これらの対応を行うことはありません。

被害の防止、事実確認、紛争への対応のため、受信した内容や受信日時など、運営者が保有する関連情報を必要な範囲・期間に限って保存・利用することがあります。保存の必要がなくなった情報は、適切に削除します。

脅迫など、安全や権利を侵害するおそれがある行為については、弁護士や警察等への相談、通報、法的措置を検討することがあります。その際に個人情報を提供する場合は、本人の同意または法令上認められる根拠に基づき、対応に必要な範囲に限定します。

## アクセス解析

以下はCloudflare Web Analyticsによるアクセス解析についての説明です。不具合報告で送信された情報の取り扱いとは区別します。

当アプリでは、サイトの利用状況を把握し、表示速度や使いやすさの改善に役立てるため、Cloudflare社のアクセス解析ツール「Cloudflare Web Analytics」を使用しています。

Cloudflare Web Analyticsは、利用者のプライバシーに配慮したアクセス解析ツールです。Cloudflareの公式説明では、個人データを収集・使用せず、個別のエンドユーザーを追跡しない仕組みであるとされています。

### 個人の追跡について

Cloudflare Web Analyticsは、CookieやlocalStorageなど、ブラウザ側に利用者を識別するための情報を保存する仕組みを使用しません。また、IPアドレスやUser-Agentなどを用いて個人をフィンガープリントする目的では使用されません。

このアクセス解析の統計から、当サイト製作者が「特定の誰かがどのページをどう移動したか」といった個人の行動を追跡することはできません。

### 利用環境のデータについて

Cloudflare Web Analyticsでは、サイト改善のため、以下のような統計情報を確認できます。

- アクセス数
- アクセス元の国
- 使用されているブラウザ
- 使用されているOS
- 端末種別
- 参照元サイト
- ページの表示速度や読み込みに関する情報

### 情報の保存と利用について

これらの情報は、どのような環境や時間帯からのアクセスが多いか、どのページがよく利用されているか、といった全体傾向を把握するために使用します。

このアクセス解析で製作者に提供される統計情報からは、利用者個人を識別する情報やIPアドレスを閲覧・保存することはできません。

### 製作者が確認できること

- アクセス数の確認
- アクセス元の国、ブラウザ、OS、端末種別などの全体傾向の確認
- どのウェブサイトやSNSのリンクから訪問されたかの確認
- ページの読み込みにかかった表示速度の確認

### 製作者が確認・操作できないこと

- 特定個人の行動ルートを追跡すること
- このアクセス解析からアクセスしてきた方のIPアドレスを閲覧・保存すること
- 訪問者個人を識別すること

### データの開示や削除について

このアクセス解析で当サイト製作者が確認できる情報は、個人を特定できない統計データに限られます。製作者側で「誰がアクセスしたか」を特定できる情報を保持していないため、この統計データから特定の利用者のアクセス記録を取り出して開示・削除することはできません。不具合報告の確認・削除については、本ポリシーの「保存と削除」および「運営・問い合わせ窓口」をご覧ください。
