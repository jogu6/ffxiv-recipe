# プライバシー・ポリシー

当アプリでは、サイトの利用状況を把握し、表示速度や使いやすさの改善に役立てるため、Cloudflare社のアクセス解析ツール「Cloudflare Web Analytics」を使用しています。

Cloudflare Web Analyticsは、利用者のプライバシーに配慮したアクセス解析ツールです。Cloudflareの公式説明では、個人データを収集・使用せず、個別のエンドユーザーを追跡しない仕組みであるとされています。

## 個人の追跡について

Cloudflare Web Analyticsは、CookieやlocalStorageなど、ブラウザ側に利用者を識別するための情報を保存する仕組みを使用しません。また、IPアドレスやUser-Agentなどを用いて個人をフィンガープリントする目的では使用されません。

そのため、当サイト製作者が「特定の誰かがどのページをどう移動したか」といった個人の行動を追跡することはできません。

## 利用環境のデータについて

Cloudflare Web Analyticsでは、サイト改善のため、以下のような統計情報を確認できます。

- アクセス数
- アクセス元の国
- 使用されているブラウザ
- 使用されているOS
- 端末種別
- 参照元サイト
- ページの表示速度や読み込みに関する情報

## 情報の保存と利用について

これらの情報は、どのような環境や時間帯からのアクセスが多いか、どのページがよく利用されているか、といった全体傾向を把握するために使用します。

当サイト製作者が、利用者個人を識別できる情報やIPアドレスを閲覧・保存することはできません。

## 製作者が確認できること

- アクセス数の確認
- アクセス元の国、ブラウザ、OS、端末種別などの全体傾向の確認
- どのウェブサイトやSNSのリンクから訪問されたかの確認
- ページの読み込みにかかった表示速度の確認

## 製作者が確認・操作できないこと

- 特定個人の行動ルートを追跡すること
- アクセスしてきた方のIPアドレスを閲覧・保存すること
- 訪問者個人を識別すること

## データの開示や削除について

当サイト製作者が確認できる情報は、個人を特定できない統計データに限られます。製作者側で「誰がアクセスしたか」を特定できる情報を保持していないため、個人情報の開示や削除といったご要望には、技術的にお応えすることができません。あらかじめご了承ください。
