# 不具合・お問い合わせの送信Worker

アプリから受け取った本文と診断情報を、外部の受付先へ`bug-report.txt`として転送するCloudflare Workerです。任意のスクリーンショットは画像ファイルとして同時に添付します。送信先URLはシークレットから読み取り、コード・応答・添付には出力しません。

## 配置と設定

`worker.mjs`が処理本体、`wrangler.jsonc`が配置設定です。Worker名は`xivca-bug-report`です。設定済みの送信先シークレットを維持し、Workerの構成でWranglerを実行します。

```powershell
npx wrangler login
npx wrangler deploy
```

`REPORT_LIMITER`は同じ接続元から60秒あたり3回を目安に制限します。`ALLOWED_ORIGINS`にはカンマ区切りの許可元を設定します。公開サイト以外で確認する場合は、そのオリジンも構成に含める必要があります。送信先や連投制限の構成が欠けている場合は、送信を受け付けません。

設定ではWorkersのログ保存、Logpush、Tail Workersへの転送を無効にしています。診断には受付本文とHTTP応答を使用します。

## 入力と送信

設定画面またはマクロパネルの「不具合・お問い合わせ」から入力します。本文は空白だけの入力と1,000文字超過をブラウザー・Workerの双方で拒否します。確認画面には本文と任意の画像を表示し、確定前のキャンセルでは送信しません。診断情報は送信に含まれますが、確認画面には表示しません。

診断情報は問い合わせ画面を開いた時点で取得し、利用環境、表示中の検索条件・レシピ・素材・チェック状態を含みます。マクロパネルを開いている場合は、生成条件、表示対象の結果、直近の計測も含みます。生成中の進行状態や保存領域の情報は、保持している記録から報告用に集計します。

画像はPNG・JPEG・WebPを4枚まで選択・貼り付けできます。元画像は1枚32MiBまでです。ブラウザーはWebP変換を試み、必要に応じて品質・解像度を調整します。元画像の方が小さい場合は元の形式を維持し、WebP出力に対応しない環境ではPNGまたはJPEGを使います。送信画像の合計は8MiBまでです。

画像なしはJSON、画像ありは`multipart/form-data`で送信します。Workerでも本文、診断情報、画像の枚数・容量・形式・識別バイトを検証し、元の画像ファイル名を汎用名へ置き換えます。診断情報の上限はUTF-8で80KiBです。

送信開始後は通信が中断しても受付済みの可能性があるため、自動再送しません。

## 確認

マクロパッケージの`npm run test:js`には、送信Workerと画像添付のテストが含まれます。ブラウザー側は主パッケージの対象を絞ったE2Eで確認できます。

```powershell
npm run test:e2e -- --grep "問い合わせ"
```

自動テストは受付先への転送をモック化します。実際の到着確認は自動テストと別の操作です。
