# フォントサイズと表示寸法の確認記録

## 現行仕様

フォントサイズ設定はLevel 1〜10で、既定値と不正値の復帰先はLevel 3です。設定モデルの相対倍率は0.8〜1.7、Level 3は1.0です。CSSの文字倍率は基準の1.1を掛けた0.88〜1.87で、Level 3は1.1になります。

文字倍率とアイコン寸法は別のCSS変数で管理しています。タイトル・アイテム・補足画像・チェックなどの寸法はLevelごとの定義を使用するため、全px値を一律に倍率変換する設計ではありません。

## 確認する寸法

| 分類               | 対象                                           | 確認内容                           |
| ------------------ | ---------------------------------------------- | ---------------------------------- |
| 文字               | 本文、ラベル、補足、選択肢                     | 選択Levelの倍率と折り返し          |
| 共通画像           | タイトル、アイテム、ジョブ、補足、チェック     | 対応するCSS変数と文字との収まり    |
| 内容に追従する寸法 | 折り畳み領域、選択肢、素材ツリー、ショップ表示 | 実測値と表示領域からの計算         |
| レイアウト         | パネル、ダイアログ、スクロール領域             | 表示幅・高さと操作領域の確保       |
| 装飾・余白         | 枠線、影、角丸、間隔                           | 文字拡大時の表示欠けや重なり       |
| レスポンシブ境界   | 600pxの切り替えと可視領域                      | 端末向き・ブラウザーUI変化への追従 |

## 確認方法

`font-size-settings.test.js`はLevel範囲、既定値、保存・適用と相対倍率を確認します。`font-size-compat.spec.js`はデスクトップ・モバイルの表示、操作部品の収まり、各Levelの互換性を確認します。可視領域とブラウザー差は`viewport-size.spec.js`でも扱います。

以前のpxトークン数・行番号は過去時点の集計であり、現在の網羅性を保証しないため掲載しません。確認範囲は現行の定義と対象テストから判断します。
