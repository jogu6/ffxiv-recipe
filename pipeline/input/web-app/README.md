# Webアプリ固定マスターデータ

このディレクトリのJSONは、Webアプリで使用する固定マスターデータの開発用原本です。JSONは非公開・ローカル専用であり、`site/`への配置、公開物への同梱、Webアプリからの実行時取得を禁止します。

## 開発時の基準

- 対象データを変更する前に、このREADMEと該当JSONを確認します。
- JSONを正とし、原則としてWebアプリ側だけを変更しません。
- 現在は自動生成処理がないため、JSONの変更と同時に`site/app.js`の対応する実行時定義も同期します。
- JSONと実行時定義で表現方法が異なる場合でも、名称、略称、所属、分類、表示順などの意味を一致させます。
- 仕様変更によって既存構造で表現できない場合は、JSONの構造変更または明示的な例外を認めます。長期的な扱いが変わる場合は、このREADMEも更新します。
- JSON変更後は構文と重複、参照関係、表示順を確認し、影響範囲に応じたnpmのチェックを実行します。

## ファイル

### `craft-jobs.json`

クラフターの製作種別ID、正式名、略称、表示順を管理します。

- `craftType`: 製作種別ID
- `name`: 正式なジョブ名
- `abbreviation`: Webアプリで使用する略称
- `order`: 0始まりの表示順

### `crystals.json`

クリスタル類の属性と種類、それぞれの表示順を管理します。

- `elements`: ファイア、アイスなどの属性
- `kinds`: シャード、クリスタル、クラスターの種類
- `order`: 0始まりの表示順

表示対象名は属性名と種類名の組み合わせから構成します。

### `equipment-roles.json`

装備検索で使用するジョブ、略称、表示順、グループ、推奨ロールとの対応を管理します。

- `jobs`: ジョブ名、略称、表示順
- `groups`: ファイター、ソーサラー、クラフター、ギャザラーの所属
- `roles`: 装備推奨ロールと対象ジョブの対応
- `casterShieldJobs`: 盾を装備候補に含める術士系ジョブ

`groups`と`roles`から参照するジョブ名は、原則として`jobs`に存在させます。

### `item-categories.json`

装備部位の表示名・表示順と、アイテムカテゴリから装備部位への対応を管理します。

- `equipmentSlots`: 部位ID、表示名、表示順
- `equipmentCategoryToSlot`: アイテムカテゴリと部位IDの対応
- `oneHandedCasterWeaponCategories`: 片手武器と盾の組み合わせ判定に使う術士武器カテゴリ

カテゴリが参照する部位IDは、原則として`equipmentSlots`に存在させます。

### `exchange-currencies.json`

交換素材を識別する製作種別と、交換・精選の分類を管理します。交換貨幣の個別名称はここへ重複保持しません。

- `craftTypes`: 交換として扱う製作種別
- `displayName`: Webアプリで使用する分類名
- `supportsRefining`: 精選を含む分類か
- `order`: 0始まりの表示順

## 非公開データの扱い

JSONファイルは`.gitignore`対象です。Gitへ追加せず、共有や環境移行が必要な場合も公開リポジトリや`site/`を経由しません。このREADMEのみをGit管理し、データの責務と運用方法を継続して共有します。
