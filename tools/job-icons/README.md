# クラフター・ギャザラー用アイコン

クラフター8職・ギャザラー3職のアイコンを、共通の生成条件と後処理条件で制作するための資料です。公開アプリには11職のWebPを同梱し、画像パックにも収録します。

## 制作仕様

- 各ジョブの参照PNGを編集対象と形状の基準として添付する
- 1ジョブにつき個別に画像生成する
- プロンプトの `{{subject}}` をジョブ定義の `subject` に置換する
- 生成背景は単色 `#00ff00`
- 前景は白と濃色の2色を基本とする
- 最終画像は透過ロスレスWebP、80×80px
- 絵柄はアスペクト比を維持して最大72×72px、中央配置する
- 輪郭のアンチエイリアスには中間色・中間アルファ値を許容する

## 定義と後処理

`jobs.json`はジョブID、日本語名、英語のシンボル説明、参照画像を対応付けます。`prompt-template.txt`は形状・配色・背景の共通生成条件です。

生成した緑背景PNGはジョブIDをファイル名にします。`build-preview-icons.mjs`は入力と出力のディレクトリを引数に取り、緑背景除去、白・濃色への変換、透過エッジ処理、80×80pxへの中央配置、ロスレスWebP出力を行います。濃色の基準値はRGB各20です。

`build-preview-sheet.mjs`はアイコンの入力ディレクトリと比較シートの出力先を引数に取り、表示確認用の画像を生成します。

## 追加・差し替えの確認

1. ジョブ定義にID、日本語名、シンボル説明、参照画像を登録する。
2. 対象のシンボル説明を埋めたプロンプトと参照画像で個別生成する。
3. ジョブIDのPNGを共通の後処理へ渡す。
4. 明暗両背景で16px、20px、24px、32px表示を確認する。
5. 採用する画像の公開配置と画像パックの整合を確認する。

画像生成には非決定性があります。同じプロンプトでも形状の完全一致は保証されないため、元アイコンとの形状比較と目視確認が必要です。
