# クラフター・ギャザラー用アイコン試作

クラフター8職・ギャザラー3職のアイコンを、同じ生成条件と後処理条件で再作成するための資料です。生成した画像が正式採用されるまでは、`site/` へコピーしません。

## 固定仕様

- 元画像は `FFXIVIcons JobIcons` 内の該当PNGを使用する
- 1ジョブにつき1回、個別に画像生成する
- `prompt-template.txt` の `{{subject}}` を `jobs.json` の `subject` に置換する
- 元画像は編集対象かつ形状参照として添付する
- 生成背景は単色 `#00ff00`
- 前景色は白と濃色の2色のみとする
- 最終画像は透過ロスレスWebP、80×80px
- 絵柄はアスペクト比を維持して最大72×72px、中央配置する
- 輪郭のアンチエイリアスだけ中間アルファ値を許可する

## 後処理

画像生成で得た緑背景PNGを、ジョブIDのファイル名で入力ディレクトリへ保存します。

```powershell
node tools/job-icons/build-preview-icons.mjs <入力ディレクトリ> <出力ディレクトリ>
```

入力ファイル名とジョブの対応は `jobs.json` が基準です。スクリプトは緑背景除去、白・濃色への2色化、透過エッジ処理、80×80pxへの中央配置、ロスレスWebPへの変換を同じ条件で実行します。

## ジョブ追加時

1. `jobs.json` にID、日本語名、英語のシンボル説明、参照画像の相対パスを追加する
2. `prompt-template.txt` に対象の `subject` を埋めて、参照画像を添付して個別生成する
3. 生成ファイルをジョブIDのPNG名で保存する
4. 後処理スクリプトを実行する
5. 明暗両背景で16px、20px、24px、32px表示を確認する

画像生成には非決定性があるため、同じプロンプトでも形状が完全一致する保証はありません。プロンプトと後処理条件は再現できますが、元アイコンとの形状比較と目視承認は毎回必要です。

比較シートは次のコマンドで作成できます。

```powershell
node tools/job-icons/build-preview-sheet.mjs <アイコンディレクトリ> <出力PNG>
```
